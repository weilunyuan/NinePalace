# NinePalace · 九宫象棋

NinePalace 是一款中国象棋桌面游戏，提供 Windows x64 便携版和本机 Web/PWA 入口。可以在校园大厅切换棋友，练习标准象棋、揭棋与王车易位，或用五位房号邀请朋友对局。

## 开始游戏

从大厅进入「人机对局」，选择玩法和执棋方后开始。执黑时 AI 先走，棋盘自动把黑棋放在下方。结算后可以查看棋谱或按同样玩法再来一局。

- **揭棋**。棋子暗置，首次走子按开局位置所对应的走法行动，落子后翻开，之后按揭出的棋子走。支持人机和远程好友对局。
- **王车易位**。开局双方各抽两枚棋子变身，支持九宫短易位。人机使用 Fairy-Stockfish，远程好友也可在「娱乐模式」开局。
- **标准象棋**。提供人机、局域网好友房和远程对局。新手教程从红方开始。

现成便携版可从 [GitHub Releases](https://github.com/weilunyuan/NinePalace/releases) 获取。开发者可按 [构建说明](./BUILD.md) 安装依赖、准备引擎并打包 Windows EXE。

## 本机 Web / PWA

```powershell
npm run web
```

保持这个终端运行，然后在浏览器打开 `http://127.0.0.1:4173/`。默认监听本机回环地址。浏览器负责界面，本地服务负责规则和人机应手。首页出现「安装 NinePalace」后可安装为桌面应用。开始对局时需要本地服务在线。

从 Windows 客户端的「好友对局」创建局域网房间，选边后把邀请链接发给同一局域网的朋友。朋友自动执另一方，刷新重连会保留原席位。Web/PWA 可用以下命令在局域网监听。

```powershell
npm run web -- --host=0.0.0.0
```

然后从主持设备的局域网地址打开应用并创建房间。房间保存在主持设备的内存中，关闭主持应用后结束。局域网邀请链接使用 HTTP，请在可信的私有网络内使用。

## 远程联机

两边使用同一版本。标准象棋从「好友对局 → 远程联机」进入，揭棋和王车易位从「娱乐模式」进入。房主点击「开房」，应用自动启动临时中转，好友用五位房号加入。双方分别选红方先手席和黑方后手席并点击「确定」，再由房主点「开始」。对局期间请保持房主应用在线。[中转说明](./relay/README.md)

## 对局复盘

从「账户 → 最近棋谱」可回放已结束的对局。标准象棋支持引擎逐手分析和推荐着法，揭棋与王车易位支持按各自规则回放。当前采用休闲对局规则。
